# Lattices from Cyclotomic rings

This project implements lattices whose coefficents come from the ring $O_K$, where $K$ is a cyclotomic extension of the rational numbers.

To obtain the underlying number fields, we have rewritten the necessary fragments from the package cyclotomic by Scott N. Walck:
    https://github.com/walck/cyclotomic
